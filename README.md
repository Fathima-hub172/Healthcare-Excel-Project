# Healthcare Messy Data Analysis 🏥

## Overview
This project explores a **messy healthcare dataset** containing patient demographics, medical conditions, and clinical metrics.  
The goal is to demonstrate **data cleaning, preprocessing, and analysis skills** while handling missing values, inconsistent formats, and duplicates.

---

## Dataset Columns
- Patient Name  
- Age  
- Gender  
- Condition  
- Medication  
- Visit Date  
- Blood Pressure  
- Cholesterol  
- Email  
- Phone Number  

---

## Features
- Identify and handle missing values (`NaN`, blanks).  
- Standardize inconsistent entries (e.g., age values like *forty* vs numeric).  
- Clean categorical fields (Gender, Condition, Medication).  
- Analyze patient health metrics (Blood Pressure, Cholesterol).  
- Prepare the dataset for visualization and reporting.  

---

## Outcomes
- **Cleaned Dataset**: Converted inconsistent values into standardized formats.  
- **Improved Data Quality**: Removed duplicates and corrected invalid entries.  
- **Health Insights**:  
  - Distribution of conditions (Asthma, Diabetes, Heart Disease, Hypertension).  
  - Medication usage patterns across patients.  
  - Relationship between age, blood pressure, and cholesterol levels.  
- **Recruiter‑Ready Portfolio**: Demonstrates ability to handle real‑world messy data and transform it into actionable insights.  

---

## Tech Stack
- **Excel**: Data cleaning, pivot tables, conditional formatting
